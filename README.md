# AutoLog

## Description
AutoLog is a JavaFX application that allows users to manage vehicle maintenance records. Users can add vehicles, record maintenance services, view service history, and view maintenance summaries.

## Running the Application

### Requirements
- Java JDK 21 or newer
- JavaFX 21
- Maven (or IntelliJ IDEA with Maven support)
- IntelliJ IDEA

### Steps
1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Allow Maven to download all project dependencies.
4. Run `AutoLogApplication.java`.

## Known Issues
- The application is intended to be run from IntelliJ IDEA.
- Data is stored in CSV files located in the project's resources directory.
- The Summary page is accessible but does not currently include a back button.
